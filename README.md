# Simuladores

Каталог интерактивных симуляторов (самодостаточные HTML-файлы). Публикуется на GitHub Pages автоматически.

## Как добавить новый симулятор

1. Положить `.html` в папку `simulators/` (можно в подпапку — она станет категорией).
2. `git add . && git commit -m "add: новый симулятор" && git push`
3. Через ~1 минуту он появится на главной странице.

Ничего вручную регистрировать не нужно — главная собирается сама из содержимого папки.

## Метаданные симулятора

Заголовок берётся из `<title>`. Опционально можно добавить в `<head>`:

```html
<title>Simulador · Название</title>
<meta name="sim:category" content="PyME">
<meta name="sim:description" content="Короткое описание для карточки">
```

Если `sim:category` не указана, категорией становится имя подпапки, иначе — «Sin categoría».

## Структура

```
simulators/           HTML-файлы симуляторов (единственное, что нужно трогать)
scripts/build.mjs     генератор главной страницы
.github/workflows/    деплой на Pages при каждом push в main
_site/                результат сборки (не коммитится)
```

## Локальная проверка

```bash
node scripts/build.mjs
npx serve _site        # или: python3 -m http.server -d _site 8000
```
